# zmxy-online

Unity 2D 横版动作 RPG 原型，目标是验证移动、攻击、技能、敌人 AI 和关卡节奏。

## 开发环境

- Unity 2022.3 LTS（项目版本：2022.3.50f1）
- Git

## 当前状态

仓库目前只有最小工程骨架和移动/生命值原型代码。请使用原创或已获授权的美术、音频和角色设定；`zmxy_res` 仅作为研究参考，不将其中的原作素材直接提交或用于公开发布。

## 下一步

1. 在 Unity Hub 导入本目录。
2. 创建 `Assets/Scenes/Prototype.unity`，添加带 `Rigidbody2D` 的玩家对象并挂载 `PlayerController2D`。
3. 添加攻击判定、敌人状态机和测试关卡。
4. 再接入原创美术和数据驱动的技能/装备配置。
