# zmxy-online

Godot 4 横版动作 RPG 原型，目标是验证移动、攻击、技能、敌人 AI 和关卡节奏。

## 开发环境

- Godot 4.x
- Git

## 当前状态

仓库目前包含最小 Godot 工程、玩家移动和生命值原型代码。请使用原创或已获授权的美术、音频和角色设定；`zmxy_res` 仅作为研究参考，不将其中的原作素材直接提交或用于公开发布。

本机素材包放在 `local_assets/`，该目录已加入 Git 忽略，不会上传到远端。

## 下一步

1. 用 Godot 4 打开本目录并运行项目。
2. 在 `scenes/prototype.tscn` 中补齐地面碰撞形状和临时角色图形。
3. 添加攻击判定、敌人状态机和测试关卡。
4. 再接入原创美术和数据驱动的技能/装备配置。
